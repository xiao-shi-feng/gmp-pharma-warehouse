# GMP 药品仓库管理 AI 系统

## 项目简介

GMP/GSP 药品仓库合规知识库与智能检索系统。
覆盖药品仓库合规管理、温湿度监控、冷链验证、批次追溯、不合格品处理等 14 大模块，
支持全文搜索、智能问答、数据管理仪表盘等功能。

## 功能特性

### 知识库系统
- 14 个知识模块，30+ 条专业条目
- 全文关键词搜索，匹配排序
- 智能问答，基于知识库自动匹配回答
- 分类浏览，按模块查看系统知识

### 数据管理仪表盘
- 仓库区域实时温湿度监控
- 物料批次全生命周期管理
- 温湿度报警记录与追溯
- 近效期预警（90天/30天分级）
- 偏差处理与不合格品管理
- 验证记录管理

### 合规支持
- 覆盖 GMP、GSP、GB/T 34399-2025 等核心法规
- CAPA 偏差管理流程
- 药品召回分级管理
- 冷链运输验证全流程
- 计算机化系统与数据完整性（ALCOA+）

## 技术栈

- 后端：Python 3 + Flask
- 前端：HTML5 + CSS3 + JavaScript
- 数据库：SQLite
- 知识库：结构化文本检索

## 安装与运行

```bash
# 1. 安装依赖
pip install flask

# 2. 启动服务
cd gmp-pharma-warehouse
python app.py

# 3. 访问
# 知识库搜索: http://127.0.0.1:5000
# 数据仪表盘: http://127.0.0.1:5000/dashboard
```

## 知识库模块

| 编号 | 模块名称 | 内容 |
|------|----------|------|
| 1 | 仓库分区与色标管理 | 三色标识、物理隔离、各区用途 |
| 2 | 仓储条件要求 | 温湿度标准、设备维护、超标处理 |
| 3 | 五距要求 | 垛/墙/柱/地/顶间距标准 |
| 4 | 物料接收与验收 | 四查规则、取样规范、供应商管理 |
| 5 | 批次管理与追溯 | 批号体系、近效期预警、全程追溯 |
| 6 | 发放原则 | FIFO+FEFO、双人复核 |
| 7 | 不合格品与退货管理 | 偏差处理、CAPA、召回管理 |
| 8 | 记录与台账要求 | 七类记录、填写规范、计算机化系统 |
| 9 | 冷库温度分布验证 | 布点方法、空载满载、开门断电测试 |
| 10 | 特殊管理药品 | 麻醉/精神/毒麻/放射性药品专库管理 |
| 11 | 冷链运输验证 | 冷藏车/保温箱验证、运输监控 |
| 12 | 温湿度监测系统验证 | 六大验证项目、报警规则 |
| 13 | 生物制品特殊冷链 | 疫苗/血液制品/生物制剂特殊要求 |
| 14 | 法规标准索引 | 法律/国标/行业标准/国际参考 |
