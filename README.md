# GMP 药品仓库合规知识库与智能问答系统

GMP/GSP 药品仓库合规管理知识库与智能检索系统，覆盖仓库合规管理、温湿度监控、冷链验证、批次追溯、不合格品处理等核心业务场景，支持全文搜索与智能问答。

**在线体验：** https://xiao-shi-feng.github.io/gmp-pharma-warehouse/

---

## 功能概述

### 知识库管理
- **29 个知识模块，49 条专业条目** — 覆盖 GMP 全部章节与 GSP 附录
- **全文关键词搜索** — 智能排序匹配，快速定位合规要求
- **智能问答模式** — 基于知识库内容自动匹配回答
- **分类浏览** — 按模块维度逐层查阅详细内容

### 数据管理仪表盘
- 仓库区域温湿度实时监控
- 物料批次全生命周期管理
- 温湿度报警记录与追溯
- 近效期分级预警（90天/30天）
- 偏差处理与不合格品管理
- 验证记录管理

### 合规支撑
- 覆盖 GMP（2010年修订）、GSP（2016年）、GB/T 34399-2025 等核心法规
- CAPA 偏差管理流程
- 药品召回分级管理（三级）
- 冷链运输验证全流程
- 计算机化系统与数据完整性（ALCOA+）

## 快速开始

### 方式一：静态页面（无需后端）

直接访问 GitHub Pages：
```
https://xiao-shi-feng.github.io/gmp-pharma-warehouse/
```

### 方式二：本地 Flask 服务

```bash
# 1. 安装依赖
pip install flask

# 2. 启动服务
cd gmp-pharma-warehouse
python app.py

# 3. 访问
知识库搜索: http://127.0.0.1:5000
数据仪表盘: http://127.0.0.1:5000/dashboard
```

### 方式三：静态导出

```bash
python export_static.py
# 静态文件输出到 static-data/
```
